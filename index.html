Política de Privacidade - Xianyu Hub

Última atualização: 31 de julho de 2026

A extensão Xianyu Hub foi desenvolvida com o compromisso de proteger a privacidade de seus usuários. Esta política explica como a extensão utiliza informações durante seu funcionamento.

Coleta de Dados

A Xianyu Hub não coleta, armazena, vende ou compartilha dados pessoais dos usuários.

A extensão não coleta informações como:

  • Nome
  • E-mail
  • Senha
  • Histórico de navegação
  • Pesquisas realizadas
  • Endereço IP
  • Cookies
  • Dados financeiros
  • Informações de identificação pessoal

Pesquisas no Xianyu

Todas as pesquisas realizadas no site Xianyu acontecem localmente entre o navegador do usuário e o próprio Xianyu. A extensão não possui acesso às pesquisas realizadas, aos produtos pesquisados ou ao histórico do usuário.

Uso de APIs

A extensão utiliza serviços externos apenas para fornecer funcionalidades como:

  • Tradução automática de anúncios.
  • Conversão automática de preços utilizando a cotação atual.

Esses serviços recebem apenas as informações estritamente necessárias para executar essas funcionalidades.

Armazenamento de Dados

A Xianyu Hub não mantém banco de dados com informações dos usuários e não realiza qualquer tipo de rastreamento.

Alterações nesta Política

Esta Política de Privacidade poderá ser atualizada sempre que necessário. A versão mais recente estará sempre disponível nesta página.

Contato

Caso tenha dúvidas sobre esta Política de Privacidade, entre em contato através do GitHub do projeto ou pelo canal oficial de suporte da extensão.
